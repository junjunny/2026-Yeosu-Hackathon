# SYM-01 | 제동력 저하·밀림 (브레이크를 잡아도 계속 진행)

문서 종류: 고급엔지니어 해결 가이드 (가상 더미 데이터). 증상은 실제 A/S 이력에서 가져왔고, 해결 내용은 시연용으로 작성한 가상 내용임.
솔루션 ID: SYM-01
기종: 파밍보이2.0A
증상: 브레이크를 잡아도 제동이 약하거나 차가 계속 밀림
증상 근거(실데이터): AS-0011(제동력 점진 저하 후 제동 불가), AS-0099(제동 불가, 계속 밀림), AS-0156(브레이크를 잡아도 계속 진행), AS-0159(패드 마모 의심, 꽉 잡아도 밀림)
실데이터 기록상 조치: 브레이크 오일 교환 또는 에어 빼기만 기록된 건이 많고 해결 여부는 모두 미확인

## 원인 후보 (확인 순서대로)
1. 오일 부족 또는 누유: 오일 탱크 양, 호스·연결부 젖음 확인
2. 에어 혼입: 에어(공기)가 오일 라인에 들어가면 압력이 전달되지 않아 페달/레버가 물렁하고 제동이 약함
3. 패드 마모 또는 오염: 패드 두께, 패드·디스크 표면에 오일이 묻었는지 확인
4. 마스터실린더 불량: 브레이크 압력을 만들어 내는 부품. 레버를 계속 잡고 있을 때 서서히 풀리면 의심

## 점검·조치 순서
1. 고객에게 증상 상황 확인 (평지/내리막, 처음부터인지 점차 심해졌는지)
2. 오일량과 외부 누유를 육안으로 확인
3. 레버 유격과 레버감 확인 (물렁함이면 에어 혼입 우선 의심)
4. 패드 두께와 오염 확인, 오염되었으면 원인(누유) 먼저 해결
5. 오일 교환 시 반드시 에어 빼기까지 한 세트로 진행 (휠별 순서는 정비 매뉴얼 기준)
6. 레버를 일정 시간 눌러 유지 시험, 서서히 풀리면 마스터실린더 점검
7. 인도 전 시험 제동 (평지 → 가능하면 경사로) 후 고객에게 결과 설명

## 고급엔지니어 핵심 포인트
- 오일 교환만으로 끝내지 않는다. 교환 후 에어 빼기와 시험 제동까지 해야 완료다.
- 같은 증상이 재발하는 차량이면 오일 교환을 반복하지 말고 3·4번(패드, 마스터실린더)으로 넘어간다.
- 규정 수치(오일 종류, 토크 등)는 정비 매뉴얼을 따른다. 이 문서에는 적지 않았다.

## 완료 확인
- 레버감 단단함, 유지 시험 통과, 시험 제동에서 정상 정지
- 이 문서는 시연용 가상 해결 가이드이며 실제 정비 매뉴얼이 아님.

# SYM-02 | 수리 후 재발하는 내리막 제동 불량

문서 종류: 고급엔지니어 해결 가이드 (가상 더미 데이터). 증상은 실제 A/S 이력에서 가져왔고, 해결 내용은 시연용으로 작성한 가상 내용임.
솔루션 ID: SYM-02
기종: 파밍보이2.0A
증상: 브레이크 수리 후 얼마 안 되어 재발, 내리막에서 제동이 안 됨
증상 근거(실데이터): AS-0093(한 달 전 브레이크 수리 후 재발, 내리막 제동 불량), AS-0112(브레이크 수리 후 재발, 내리막 제동 불가), AS-0110(내리막 제동 불량으로 정지 못함), AS-0177(내리막 제동 불가)
실데이터 기록상 조치: 오일 교환, 에어 빼기, 캘리퍼 교체 등. AS-0112는 "누유 없음"으로 기록. 해결 여부는 모두 미확인

## 원인 후보 (확인 순서대로)
1. 오일 열화·수분: 내리막에서 계속 브레이크를 쓰면 열이 올라 오래된 오일이 끓어 기포가 생기고 제동이 빠짐 (베이퍼락)
2. 마스터실린더 내부 누유: 밖으로 새지 않아도 내부에서 압력이 빠질 수 있음
3. 캘리퍼 피스톤 고착: 캘리퍼가 패드를 제대로 조이지 못하거나 풀리지 않아 한쪽 제동이 약해짐
4. 패드 표면 경화(글레이징): 열을 받아 패드 표면이 딱딱해져 마찰이 줄어듦

## 점검·조치 순서
1. 이전 수리 내용(무엇을 교체·교환했는지, 언제인지)을 먼저 확인
2. 오일 색과 상태 확인, 이전에 오일 교환을 했는데도 재발이면 오일이 원인이 아닐 가능성이 높음
3. 외부 누유가 없어도 결론 내리지 말고 레버 유지 시험으로 마스터실린더 내부 누유 확인
4. 좌우 휠 열 상태·회전 저항 차이 확인 (한쪽만 심하면 캘리퍼 의심)
5. 패드 표면 상태 확인
6. 부품 교체 후 에어 빼기, 경사로 시험 주행으로 재현 여부 확인

## 고급엔지니어 핵심 포인트
- "누유 없음"은 원인 없음이 아니다. 내부 누유와 캘리퍼 쪽을 끝까지 본다.
- 재발 건은 이전과 똑같은 조치를 반복하지 않는다.
- 내리막 증상은 평지 시험으로는 재현이 안 될 수 있으니 경사로에서 확인한다.

## 완료 확인
- 경사로 시험 제동 통과, 좌우 제동 균형 확인
- 이 문서는 시연용 가상 해결 가이드이며 실제 정비 매뉴얼이 아님.

# SYM-03 | 제동 시 소음 (딱딱 소리, 양쪽 브레이크 소음)

문서 종류: 고급엔지니어 해결 가이드 (가상 더미 데이터). 증상은 실제 A/S 이력에서 가져왔고, 해결 내용은 시연용으로 작성한 가상 내용임.
솔루션 ID: SYM-03
기종: 파밍보이2.0A
증상: 제동 시 또는 주행·제동 시 브레이크 쪽에서 소음
증상 근거(실데이터): AS-0100(내리막 제동 시 딱딱 소리), AS-0102(양쪽 브레이크 소음, 주행·제동 시)
실데이터 기록상 조치: 소음 설명 및 브레이크 조정(AS-0100), 양쪽 패드 교환(AS-0102). 해결 여부는 모두 미확인

## 원인 후보 (확인 순서대로)
1. 패드 마모 한계: 마모가 심해 금속이 닿으면 소음 발생
2. 패드 고정 부품 헐거움: 패드가 흔들리며 딱딱 소리
3. 캘리퍼 또는 휠 쪽 볼트·너트 풀림
4. 디스크 표면 이물 또는 편마모
5. 신품 패드 초기 길들이기 부족

## 점검·조치 순서
1. 소음이 나는 조건 확인 (제동할 때만 / 주행 중에도, 내리막, 한쪽 / 양쪽)
2. 패드 두께와 마모 상태 확인
3. 패드 고정 부품과 캘리퍼 체결 상태 확인
4. 디스크 표면 확인
5. 필요한 경우에만 패드 교환 (원인 확인 전에 부품부터 바꾸지 않는다)
6. 교체했다면 길들이기 주행 방법을 고객에게 안내
7. 시험 제동으로 소음 재현 여부 확인

## 고급엔지니어 핵심 포인트
- 소음은 조건을 먼저 묻고 원인을 확인한 뒤 교체한다.
- 패드를 갈았으면 길들이기 안내까지 해야 고객 재방문이 줄어든다.
- 토크 등 규정 수치는 정비 매뉴얼을 따른다.

## 완료 확인
- 같은 조건에서 시험 제동 시 소음 없음
- 이 문서는 시연용 가상 해결 가이드이며 실제 정비 매뉴얼이 아님.
