# 이 폴더의 작업 범위

`frontend/`는 사용자가 담당하는 작업을 모으는 폴더입니다. 기술적으로 화면 코드에 해당하는 파일만 담는다는 뜻이 아닙니다. 이 작업에서 생성하는 코드, 개발 문서, 스킬 설정 등은 이 폴더 안에서 관리합니다. 공동 작업자의 `backend/`를 수정할 때는 별도 요청과 연동 범위를 확인합니다.

수정 전 `HANDOFF.md`와 `README.md`를 읽으세요. 최신 사용자 요청이 문서보다 우선합니다. `docs/development-plan.md`는 초기 계획으로 보관한 자료이며, 최신 동작과 차이가 있습니다.

설치된 스킬은 `.agents/skills/`에 있고 설치 기록은 `skills-lock.json`에 있습니다. 해당 스킬을 적용할 때는 각 `SKILL.md`를 먼저 읽으세요.
