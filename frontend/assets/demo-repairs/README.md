# 완료 사례용 합성 시연 자료

실제 고객 사진이나 실제 고객이 작성한 서명이 아닙니다. 이미지 생성 도구로 만든
해커톤용 합성 자료이며, 화면과 이미지에 시연용 표시를 유지합니다.

| 파일 | 합성 고객 | 사용 내용 |
| --- | --- | --- |
| `charging-before-after.png` | 류병철 · FARMINGBOY-CUS-094 | 열 손상 충전플러그 → 교체 후 연결 상태 |
| `fuse-before-after.png` | 전보람 · FARMINGBOY-CUS-093 | 손상된 10A 퓨즈 → 교체 후 라이트 점등 |
| `signatures.png` | 위: 류병철 / 아래: 전보람 | 볼펜 손글씨 형태의 수리 동의·최종 확인 서명 |

생성된 원본 PNG를 그대로 보관합니다. 서명 시트의 위·아래 영역은 CSS 배경 위치로
나누어 표시합니다. 사진은 같은 구도의 수리 전후 비교판으로 표시합니다.

## 생성 프롬프트 요약

- 충전플러그: 소형 농업용 전동 운반차의 실제 정비 기록 같은 사진. 같은 구도에서
  왼쪽은 열 손상과 접촉 불량이 있는 충전 연결부, 오른쪽은 깨끗하게 교체한 연결부.
  BEFORE / AFTER 구분과 AI GENERATED DEMO 표시. 사람 얼굴이나 실제 개인정보 없음.
- 메인퓨즈: 소형 농업용 운반차 전장부의 수리 전후 사진. 왼쪽은 손상된 10A 퓨즈와
  꺼진 라이트, 오른쪽은 교체된 퓨즈와 켜진 라이트. 같은 장비와 구도, 자연스러운
  현장 먼지·조명. BEFORE / AFTER 및 AI GENERATED DEMO 표시.
- 서명: 흰 종이 위 자연스러운 한국어 볼펜 손글씨를 두 가로 영역으로 분리.
  위쪽 이름은 “류병철”, 아래쪽 이름은 “전보람”. 서로 다른 필압과 필체,
  인쇄 글꼴처럼 보이지 않는 연속적인 펜 획, 각 영역에 작은 DEMO 표시.

## 연결 및 검증

`enrichCompletedDemoEvidence()`가 지정된 합성 완료 사례 2건만 한 번 보강합니다.
다른 고객의 상담·사진·서명과 기존 체크리스트/수리 흐름은 유지합니다.
새 이미지 경로는 FastAPI의 명시적 파일 허용 목록으로만 제공합니다.

확인: 백엔드 12개 테스트, 워크플로 12개 테스트, 상담→팀장 컨펌→현장 완료
UI 스모크, 실제 Chromium의 데스크톱/390px 모바일 사진·서명·Help 병행 표시,
오늘 완료 5건의 고객별 기록, 공개 배포 URL의 이미지 응답.
