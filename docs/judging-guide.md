## 제출 체크리스트와 확인 위치

사용자가 제공한 「2026 전남광주 기업 AX 혁신챌린지 제출 전 체크리스트」를 기준으로 정리했습니다. 별도 심사 배점표는 제공되지 않아 점수·가중치를 추정하지 않았습니다.

| 확인 항목 | 확인 방법·증거 |
| --- | --- |
| 다른 기기·시크릿 창 접속 | 공개 URL, 독립 브라우저 3개 기록 공유 검증 |
| 처음 보는 사용자 체험 안내 | 루트 README, 역할 버튼, 팀장 비밀번호 화면 안내 |
| 더미·비식별 데이터 | web/data 합성 고객, knowledge 문서별 출처·비식별 설명 |
| 발표·심사 중 서비스 유지 | ops/README.md, runit 포트 8501 감독 실행 |
| 저장소 열람 | 공개 GitHub main |
| 서비스 소개·실행 방법 | 루트 README, docs/development.md |
| API 비밀키 제외 | config/.env.example만 공개, .gitignore, HTTP 허용 파일 목록 |
| 마지막 수정 반영 | main 커밋과 배포 파일 일치 확인 |

발표자료 템플릿·PDF 글꼴·발표 시간·녹화 영상·USB·온라인 제출은 파일 또는 제출 증빙이 필요하며, 코드 구조 정리만으로 완료 처리하지 않습니다.

## 구현 위치

- 역할별 업무·모바일 화면: web/
- 챗봇 API 연결·저장·배차·보고서: server/
- 챗봇 참고 지식: knowledge/
- 검증 결과: docs/submission-check.md 및 tests/

프로토타입은 사용자별 서버 인증·권한을 구현하지 않았습니다. 팀장 비밀번호 1234는 공개 체험 장치이며 실제 운영 비밀번호가 아닙니다.
