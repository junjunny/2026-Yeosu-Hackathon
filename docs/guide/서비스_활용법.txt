FIELDNOTE · 심사위원 서비스 활용법

1. 처음이라면, 이 순서로 해보세요
Fieldnote는 농기계 수리 접수부터 현장 수리 완료까지 체험하는 서비스입니다. 프로그램 설치나 회원가입 없이 휴대폰·PC 브라우저에서 사용할 수 있습니다.

서비스 주소
https://devopen-gpu.jntp-ax.or.kr/i/XUYja4vr7_KF-hZ5/

체험 순서
① 상담사: 고객의 이름과 증상을 접수합니다.
② 팀장: 상담 내용을 확인하고 우선순위를 확정합니다.
③ 엔지니어: 점검·견적·사진·서명을 기록합니다.
④ 결과 확인: 고객용 PDF와 회사용 엑셀을 내려받습니다.

시작하기
1. 위 주소를 열어 주세요. 기존 탭이 있다면 새로고침해 주세요.
2. 화면 위의 ‘상담사’를 선택하고 ‘새 상담 시작’을 누릅니다.
3. 입력칸을 누르면 시연용 보기가 나타납니다. 원하는 문구를 누르면 입력됩니다.
4. 팀장 화면의 체험용 비밀번호는 1234입니다.

함께 알아두세요
• 같은 주소를 사용하는 사람은 같은 기록을 봅니다. 시크릿 창도 마찬가지입니다.
• 실제 개인정보·사진·서명 대신 이 자료의 가상 정보와 테스트 사진을 사용해 주세요.
• 여러 명이 동시에 체험하면 이름을 ‘한준희-01’, ‘한준희-02’처럼 구분해 주세요.
• 휴대폰에서 고객 목록이 안 보이면 ‘목록 보기’를 누릅니다.

이 묶음에는 안내서, 복사할 입력 문구, 사진 첨부용 테스트 이미지가 들어 있습니다. 시연 영상은 별도로 추가할 수 있습니다.

2. ① 상담사 — 고객의 말을 접수해요
새 상담 시작
1. ‘상담사’를 선택한 뒤 ‘새 상담 시작’을 누릅니다.
2. 아래 내용을 입력하거나 입력칸의 보기를 선택합니다.

고객 이름: 한준희
등록 주소: 전남광주 나주시 금성관길 6-1
출동 장소: 전남광주 나주시 금성관길 6-1
장비 식별 정보: 이번 체험에서는 비워 두어도 됩니다.

3. ‘상담 시작’을 누릅니다.
4. 고객이 말한 증상을 아래처럼 입력하고 전송합니다.
“딱딱 소리가 나고, 브레이크가 밀리는 것 같다.”
5. 챗봇이 안내하는 고객 응대 내용과 다음 행동을 확인합니다.

통화를 마무리해요
6. ‘통화 종료’를 눌러 확인 화면을 엽니다.
7. 이 체험에서는 아래처럼 선택합니다.
• 접수 구분: 고장 / 상담 우선순위: 상
• 방문 요청: 예 / 주행 불가능: 예 / 직접 조치 희망: 아니요
• 일반 건 출동 여부: 출동
8. ERP 확인란에는 아래 예시를 입력합니다.
• 과거 수리 이력: 과거 수리 이력 없음
• 제품명: 파밍보이2.0A / 구입 시점: 2023.08.19
• 출동 장소: 처음 입력한 주소 확인
9. ‘통화 종료 · 기록 잠금’을 누릅니다.

성공 확인
화면 위에 ‘서버 저장 완료’가 표시되면 접수가 저장된 것입니다. 종료된 상담 원문은 이후 엔지니어가 읽어볼 수 있습니다.

3. ② 팀장 — 내용을 확인하고 넘겨요
팀장 화면 열기
1. 화면 위의 ‘팀장’을 누릅니다.
2. 비밀번호 1234를 입력하고 ‘팀장 화면 열기’를 누릅니다.
3. 오늘 접수 목록에서 방금 입력한 고객을 찾습니다.

우선순위 확인과 최종 컨펌
4. 상담 요약과 고객의 증상을 읽습니다.
5. 우선순위를 확인하고 확정 버튼을 누릅니다.
6. ‘최종 컨펌’을 눌러 현장 전달을 진행합니다.
7. ‘서버 저장 완료’ 표시를 확인합니다.

대시보드는 이렇게 보세요
• 오늘 접수: 상담사가 오늘 접수한 고객입니다.
• 오늘 기사 진행 현황: 이미 방문 중인 기사들의 완료·예정 상황입니다.
• 내일 배차 계획: 다음 방문 일정의 기사별 방문 순서를 확인하는 영역입니다.

오늘 접수했다고 오늘 바로 수리하는 것은 아닙니다. 체험에서는 전체 흐름을 확인하기 위해 팀장 확인 후 현장 단계로 이어갑니다.

다음 화면으로 이동
8. 화면 위의 ‘엔지니어’를 누릅니다.
9. 담당자 목록에서 배정된 기사를 선택하고 방금 접수한 고객을 엽니다. 기본 시연에서는 엔지니어 A에서 확인합니다.

고객이 보이지 않으면
• 잠시 기다려 공유 기록이 반영됐는지 확인합니다.
• 팀장 최종 컨펌이 완료됐는지, 기사와 고객을 맞게 골랐는지 확인합니다.
• ‘배차 대기’이면 기사 업무 한도에 도달한 상태입니다. 기존 예정 건을 완료한 뒤 팀장 화면의 ‘배차 재시도’를 사용합니다. 중복으로 새 상담을 만들 필요는 없습니다.

4. ③ 엔지니어 — 점검하고 수리해요
도착과 점검
1. 상담 요약을 읽고 필요하면 원문 대화도 펼쳐 봅니다.
2. 도착 입력칸에 ‘현장 도착’을 입력하고 저장합니다.
3. 체크리스트를 확인한 뒤 항목을 체크합니다.
4. 점검 결과에는 입력칸의 보기를 선택합니다.
“브레이크 문제로 출동했지만, 현장에서 함께 점검한 결과 앞 타이어 2개의 마모 상태도 좋지 않은 것을 확인했습니다.”

도움이 필요할 때
‘Help’를 누르고 질문해 보세요. ‘작업 화면으로 돌아가기’를 누르면 점검을 계속할 수 있습니다.
질문 예시: “딱딱 소리날 때 뭘 봐야 하더라. 좀 알려줘.”

사진과 견적
5. ‘수리 전 사진’에 동봉한 ‘수리전_테스트.png’를 첨부하고 저장합니다.
6. 수리 예정 내용의 보기를 선택합니다.
“제동 성능을 회복하기 위해 브레이크 패드를 교체하고, 마모가 심한 앞 타이어 2개를 함께 교체할 예정입니다.”
7. 부품 검색에서 ‘브레이크’를 입력해 브레이크 패드를 선택합니다. 이어 ‘타이어’를 검색해 앞 타이어를 선택하고 수량을 2개로 입력합니다.
8. 출장비와 총액을 확인하고 견적을 제출합니다. 이 나주 주소의 출장비는 33,000원입니다.
9. 고객 동의 항목에 체크하고 서명 영역에 가상 서명을 그린 뒤 저장합니다. 직접 그리기 어려우면 가상 고객 이름을 입력할 수 있습니다.

테스트 사진은 업로드 기능을 확인하는 표시용 이미지이며 실제 수리 사진이 아닙니다. 사진은 수리 전·후 각각 최대 5장까지 첨부할 수 있습니다.

5. ④ 완료 — 결과 파일을 확인해요
수리 완료하기
1. 실제 수리 결과 입력칸의 보기를 선택하고 저장합니다.
“브레이크 패드와 앞 타이어 2개를 교체했습니다. 교체 후 제동 상태와 주행 상태를 다시 점검했으며, 장비가 정상적으로 작동하는 것을 확인했습니다.”
2. ‘수리 후 사진’에 ‘수리후_테스트.png’를 첨부하고 저장합니다.
3. 개인정보 처리 안내와 수리 이행 확인 항목을 확인해 체크합니다.
4. 가상 고객의 최종 서명을 입력하고 저장합니다.

고객용 PDF 받기
5. 완료 화면의 ‘수리 완료 안내서 PDF’를 누릅니다.
수리 내용·비용·사진·서명을 담은 파일입니다. 필요할 때 고객에게 전달하거나 출력할 수 있으며 자동 발송되지는 않습니다.

사내 비고와 엑셀 확인
6. PDF 버튼 아래 ‘비고’는 회사 내부 참고사항을 적는 곳입니다. 이번 체험에서는 빈칸으로 두어도 됩니다.
비고는 고객용 PDF에 들어가지 않고, 회사용 엑셀의 마지막 열에만 포함됩니다.
7. ‘팀장’ 화면으로 돌아가 고객의 완료 상태를 확인합니다.
8. ‘최신 누적 이력 엑셀 다운로드’를 누릅니다.
기존 완료 이력과 방금 완료한 고객의 기록이 함께 들어 있습니다. 파일을 새로 내려받을 때 최신 기록이 반영됩니다.

막혔을 때 확인할 것
• 버튼이 눌리지 않음: 빈 필수 입력칸·체크 항목·사진·서명을 확인합니다.
• 저장 중 또는 연결 오류: 완료 표시를 기다립니다. 작성 중에는 바로 창을 닫지 마세요.
• 챗봇 응답 오류: 외부 연결 상태를 확인한 뒤 다시 시도합니다.
• 휴대폰에서 파일이 안 보임: 브라우저 다운로드 목록 또는 파일 앱을 확인합니다.

여기까지 하면 상담 접수부터 수리 완료, 결과 파일 확인까지 체험한 것입니다. 직접 입력한 기록은 공유 데모에 저장됩니다.
